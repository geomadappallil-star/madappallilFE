# 🌿 Madappallil Homoeo Dispensary (MHD)

> **35+ Years of Compassionate Healing Excellence**  
> Specialized Homoeopathic Care for **Infertility Treatments** and **Mental Health & Disorders**

---

## 🌟 Key Highlights

- **Bilingual Interface**: Full, seamless toggling between **English** and **Malayalam (മലയാളം)** with high-legibility Malayalam typography.
- **Brand & Monogram**: Custom **MHD** monogram logo badge honoring 35+ years of clinical service.
- **Focused Specializations**:
  - **Infertility & Natural Conception**: PCOD/PCOS, Low AMH, Tubal blockages, Endometriosis, Male factor oligospermia, Recurrent miscarriages.
  - **Mental Health & Emotional Well-Being**: Anxiety disorders, Clinical depression, OCD, Panic attacks, Chronic insomnia, Psychosomatic conditions.
- **Interactive Visual Storytelling**:
  - High-resolution, serene clinic ambiance, parenthood miracles, mental tranquility, and botanical homoeopathic medicine photography.
  - Interactive picture inspection lightbox and category filters.
  - 4-step constitutional healing process visualizer.
- **Zero-Friction Lead Capture & Workflow**:
  - Direct submission into **Google Sheets**.
  - Automated instant email alerts sent to the Chief Doctor's email inbox with 1-click "Call Patient" and "WhatsApp" buttons.
  - Built-in Local Leads Vault with **CSV Export**.
  - Confetti celebration and prefilled direct WhatsApp connect button.

---

## 💻 Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS (custom botanical healing palette)
- **Icons**: Lucide React
- **Typography**: Inter + Noto Sans Malayalam + Manjari + Playfair Display

---

## 🛠️ Development & Deployment

### Quick Start
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Google Sheets Integration Setup
Refer to [`GOOGLE_SHEETS_SETUP_GUIDE.md`](./GOOGLE_SHEETS_SETUP_GUIDE.md) or click the **Settings (gear)** icon on the website to copy the Google Apps Script code and paste your Web App URL.
